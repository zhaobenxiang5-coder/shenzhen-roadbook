# 深圳龙岗丹平出发 · 避坑反向自驾路书 (中秋3天 + 国庆5天)

> 专为**情侣两人出行、厌恶人挤人、拒绝高价房费、当日往返回家睡**量身打造的开源自驾路书交互 Web App。

## 🌟 核心特色

1. **基地化日归（0房费）**：
   - 以**深圳龙岗丹平社区（南湾/平湖）**为辐射圆心，单程控制在 25 ~ 85 分钟车程内。
   - 每天自驾玩完回深圳丹平睡舒服大床，彻底避开节假日暴涨 5~10 倍的度假酒店。
2. **厌人反向选点**：
   - 彻底避开大梅沙、较场尾正滩、深圳湾、梧桐山主峰等“地狱级堵点”。
   - 精选坪山碧岭瀑布群、坝光古银叶树海岸、惠阳秋长谷里古村、深汕百安海滩、东莞第一峰等冷门高颜值秘境。
3. **双重平替机制（A/B自由切换）**：
   - 每一个目的地与美食均设计了【主选 A】与【避堵平替 B】。
   - 路上遇到突发缓行或天气变化，手机一点直接切换备选方案。
4. **高德地图一键导航直达**：
   - 每个景点、停车场及特色美食均配置了真实的高德一键导航链接，点击直接唤起高德地图 App 规划行车路径。
5. **单文件零依赖（Mobile-First）**：
   - 输出单一纯静态 `index.html`，无需服务器、无需数据库，手机微信直接打开即可流畅体验。

## 📅 行程概览

### 🌕 中秋 3 天假期 (山野清凉 · 观海赏月)
- **Day 1**：马峦山碧岭瀑布群 + 大万世居客家围屋月夜（平替：龙岗园山风景区 / 南湾潮汕牛肉火锅）
- **Day 2**：大鹏坝光古银叶树湿地 + 白沙湾落日赶海（平替：惠阳澳头小桂村沿海绿道 / 澳头现捞海鲜码头）
- **Day 3**：东莞塘厦大屏嶂森林公园 + 水库漫步寻正宗碌鹅（平替：龙岗红花岭生态公园 / 平湖守珍街老铺）

### 🇨🇳 国庆 5 天黄金周 (避堵反向 · 纯净海滩 · 岭南寻味)
- **Day 1 (10.1 全网首日大堵车)**：逆向不出深，凤岗官井头水库/平湖生态园草坪放空 + 客家黄鳝饭
- **Day 2 (10.2)**：避世田园，惠阳秋长谷里客家古村落漫步 + 柴火三杯鸭（平替：观澜版画村）
- **Day 3 (10.3)**：深汕鲘门百安纯净沙滩踩水 + 渔港海鲜红鲟饭（平替：大鹏杨梅坑清晨追光快线）
- **Day 4 (10.4)**：深中通道飞驰跨海 + 顺德容桂老街市井私房桑拿鸡（平替：中山南朗崖口稻田海景）
- **Day 5 (10.5 黄金周收官)**：东莞第一峰银瓶山溪谷沿溪洗肺收心（平替：盐田三洲田公路自驾慢游）

## 📱 使用与分享指南

1. **直接查看**：双击直接在任何浏览器打开 `index.html`。
2. **手机上查看**：
   - 可以在本地终端运行快速 HTTP 服务（如 `python3 -m http.server 8080`），手机连接同一 WiFi 访问手机 IP 即可体验。
   - 也可以将 `index.html` 部署到 Vercel、GitHub Pages 或 Cloudflare Pages，生成随时随地微信点开的访问链接！
